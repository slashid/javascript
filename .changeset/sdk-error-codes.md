Show dedicated error screens for the `email_domain_routed_not_member` and `console_sso_sign_in_required` API codes (text keys `error.{title,subtitle,retry}.emailDomainRoutedNotMember` and `error.{title,subtitle,retry}.consoleSSOSignInRequired`). The screens appear with `@slashid/slashid` 3.32.0 or later; older supported SDKs keep the existing screens.
